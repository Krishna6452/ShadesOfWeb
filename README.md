# Shades of Web

**Shades of Web** is a web development project showcasing a variety of web design components, including galleries, carousels, and responsive layouts, built with **React.js** and **Tailwind CSS**.

## Features
- Responsive design using **Tailwind CSS**
- Interactive image carousel
- Dynamic grid gallery components
- Easily customizable and reusable code structure
